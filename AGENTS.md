# Instruções para assistentes de código

- Preserve a identidade minimalista da Acta.
- Não envie documentos para serviços externos sem autorização explícita.
- Mantenha o modo de planejamento antes da execução.
- Toda saída deve indicar as fontes e lembrar que exige conferência humana.
- Nunca adicione chaves, credenciais ou documentos jurídicos reais ao repositório.
- Execute os testes antes de registrar uma versão.
